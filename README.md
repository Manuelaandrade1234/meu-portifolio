Entre os projetos apresentados no meu portfólio estão aplicações desenvolvidas para diferentes necessidades.

- Produtos
- Clientes
- Caixa
- Financeiro
- Delivery
- Relatórios
- Gestão de usuários
- Multiempresa
- Super Admin

### Beauty Hub

Sistema voltado para estabelecimentos do segmento de beleza.

Possui recursos como:

- Agendamento de horários
- Área do cliente
- Área do profissional
- Cadastro de clientes
- Gestão de profissionais
- PDV
- Dashboard administrativo

### Contas Inteligentes

Aplicação desenvolvida para gerenciamento de contas e vencimentos.

Entre suas funcionalidades estão:

- Cadastro de contas
- Controle de pagamentos
- Identificação de contas vencidas
- Dashboard financeiro
- Filtros por período
- Parcelamento automático
- Leitura de boletos utilizando OCR

### Agenda de Contatos

Aplicação CRUD desenvolvida em PHP e MySQL para gerenciamento de contatos.

Permite:

- Cadastrar contatos
- Visualizar registros
- Editar informações
- Excluir contatos

### Blog Codar

Blog desenvolvido em PHP para publicação e organização de conteúdos relacionados à programação.

O projeto trabalha conceitos como:

- PHP
- Arrays
- Conteúdo dinâmico
- Tags
- Categorias
- Reutilização de componentes

### HealthyMind

Meu primeiro projeto desenvolvido na faculdade.
